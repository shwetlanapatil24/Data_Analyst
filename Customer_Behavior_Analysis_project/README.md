## Usage Instructions
1. **Clone the repository**:  
   ```bash
   git clone https://github.com/shwetlanapatil24/Data_Analyst.git
   ```
2. **Navigate to the project folder**:  
   ```bash
   cd Data_Analyst/Customer_Behavior_Analysis_project
   ```
3. **Install required Python packages**:  
   ```bash
   pip install -r requirements.txt
   ```
4. **Run analysis notebooks**: Open Jupyter Notebook and run the notebooks located in the `notebooks/` directory.
5. **View visualizations in Power BI**: Open the Power BI files located in the `visualizations/` directory to explore the dashboards.
